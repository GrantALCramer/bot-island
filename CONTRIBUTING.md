# Contributing

Thanks for helping! Bug reports, ideas and pull requests are welcome.

- **Bugs / ideas:** open an issue with your version, platform and steps to reproduce (no access keys or personal data).
- **Security issues:** see [SECURITY.md](SECURITY.md); please report privately.
- **Development:** `npm install`, then `npm run dev` (or `npm start`). See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
- **Pull requests:** keep them focused, run `npx vite build` before submitting, and describe what you tested.
  Themes are a great first contribution (see `src/themes/`).

By contributing you agree your work is released under the [MIT License](LICENSE).
